## 기기별로 미리 알려드리는 것

| 기기 | 예상되는 차이 |
|---|---|
| PC Edge | 가장 잘 돼요. 에바 음성은 Edge의 Natural 음성(Ava·Jenny)을 자동 선택해요. |
| PC Chrome | 음성 인식 OK. 에바 음성은 Google US English로 조금 기계적일 수 있어요. |
| 아이폰 Safari | 녹음은 `audio/mp4`로 저장돼요. 음성 인식은 iOS 설정 → Siri 및 받아쓰기가 켜져 있어야 하고, 간혹 끊겨요. **설치(홈 화면 추가)는 공유 버튼 → "홈 화면에 추가"**. |
| 안드로이드 Chrome | 음성 인식 OK. 설치는 주소창 메뉴 → "앱 설치". 일부 기기는 마이크 권한을 사이트 설정에서 다시 켜야 해요. |

## 자주 생기는 문제와 대처

| 증상 | 해보기 |
|---|---|
| 에바 목소리가 안 나옴 | 무음 모드 해제, 볼륨 확인, 화면을 한 번 터치한 뒤 다시 "질문 듣기" |
| 마이크 권한 팝업이 안 뜸 | 주소창 자물쇠 → 사이트 설정 → 마이크 "허용" |
| 스크립트가 안 적힘 | 마이크 권한과 인터넷을 확인하고 조금 더 또렷하게 말해보세요. 타이핑 입력은 없어요(말로만) |
| 옛 화면이 보임 | 새로고침 2번 (서비스워커가 새 파일을 받아요) |
