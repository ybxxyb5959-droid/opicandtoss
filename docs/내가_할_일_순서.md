## 2. Cloudflare Worker 배포 (15분)

PowerShell 또는 Git Bash에서 한 줄씩 실행해요.

```bash
cd C:\Users\krime\opicbin\worker
```
```bash
npx wrangler login
```
→ 브라우저가 열리면 Cloudflare에 로그인하고 **Allow**.

```bash
npx wrangler kv namespace create QUOTA
```
→ 결과에 `id = "xxxxxxxxxxxxxxxx"` 가 나와요. 그 값을 `worker/wrangler.toml` 파일의 `id = "REPLACE_WITH_YOUR_KV_NAMESPACE_ID"` 자리에 붙여넣고 저장. (이 부분은 저에게 "KV id는 xxxx야"라고 알려주시면 제가 넣어드려도 돼요. KV id는 비밀이 아니에요.)

```bash
npx wrangler secret put GEMINI_API_KEY
```
→ 입력창이 뜨면 1번에서 받은 키를 붙여넣고 Enter. (화면에 안 보여도 정상)

```bash
npx wrangler secret put INVITE_CODES
```
→ 친구들에게 줄 초대 코드를 쉼표로 적어요. 예: `MALMUN01,MALMUN02,MALMUN03,MALMUN04,MALMUN05,MALMUN06`
   (영문 대문자+숫자, 사람마다 다른 코드를 주면 누가 얼마나 쓰는지 나뉘어 계산돼요)

```bash
npx wrangler deploy
```
→ 마지막 줄에 `https://malmun-coach.<내계정>.workers.dev` 주소가 나와요. **이 주소를 저에게 알려주세요.** 제가 `app.js` 맨 위 `COACH_API_BASE`에 넣어 드릴게요. (주소는 비밀이 아니에요)

확인:
```bash
curl "https://malmun-coach.<내계정>.workers.dev/quota?deviceId=test" -H "Origin: http://localhost:4180"
```
→ `{"remainingToday":3,"limit":3,"member":false}` 가 나오면 성공.

## 3. 앱에 서버 주소 연결 (제가 함)

주소를 알려주시면 `app.js`의 `COACH_API_BASE` 한 줄을 바꾸고 커밋해요. 그 뒤 로컬(`localhost:4180`)에서 설정 → "오늘 AI 첨삭 남은 횟수"가 숫자로 보이면 연결 성공.

## 4. 내 기기에서 확인 (20분)

`docs/모바일_점검_체크리스트.md` 12개 항목을 PC에서 먼저 확인해요. 특히:

- 답변 후 Gemini 첨삭이 뜨는지, 꼬리질문이 읽히는지
- 설정에 초대 코드 넣으면 남은 횟수가 50으로 바뀌는지

## 5. 푸시 + GitHub Pages 배포 (제가 함, 확인 후)

"푸시+배포 진행"이라고 말씀하시면:
1. 커밋 전부를 GitHub main에 푸시
2. GitHub 저장소 → Settings → Pages → Branch: `main` / `(root)` → Save (이건 화면 안내해 드릴게요, 1분)
3. 1~2분 뒤 https://ybxxyb5959-droid.github.io/opicandtoss/ 확인
4. Worker의 허용 주소(ALLOWED_ORIGINS)에 이 주소가 이미 들어 있어요

## 6. 친구들에게 보내기

배포 주소 + 초대 코드 1개씩 + 설치 방법(아이폰: 공유 → 홈 화면에 추가 / 안드로이드: 메뉴 → 앱 설치)을 보내면 끝. 안내 문구는 배포 후 제가 짧게 써드릴게요.

## 나중에 알아두면 좋은 것

| 상황 | 하는 법 |
|---|---|
| 초대 코드 바꾸기/추가 | `cd worker` → `npx wrangler secret put INVITE_CODES` 다시 실행 → `npx wrangler deploy` |
| Gemini 키 바꾸기 | `npx wrangler secret put GEMINI_API_KEY` → `npx wrangler deploy` |
| 오늘 누가 얼마나 썼는지 | Cloudflare 대시보드 → Workers & Pages → KV → QUOTA 에서 `q:날짜:code:코드` 값 |
| Gemini 무료 한도 | https://aistudio.google.com/rate-limit 에서 모델별 하루 요청 수 확인. 초과하면 앱이 자동으로 내장 코치로 전환 |
| 앱 업데이트 | 제가 커밋 → 푸시하면 친구들 앱은 다음 실행 때 자동 갱신 (새로고침 2번) |
